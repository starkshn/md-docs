# Blog Convention

## 목적

기술 블로그는 단순 구현 기록이 아니라 학습, 구조 분석, 문제 발견, 재설계 이유를 보여주는 글이어야 한다.

## 기본 구조

```text
1. 이 개념을 공부한 이유
2. 개념 설명
3. 강의 또는 기존 구조 분석
4. 현재 프로젝트와 맞지 않았던 점
5. 재설계 방향
6. 최종 구현 구조
7. 문제 상황과 해결
8. 결과
9. 개선 방향
10. 면접에서 설명할 포인트
```

## 제목 규칙

- 구현 기능보다 설계 의도가 드러나야 한다.
- “만들기”보다 “왜 이렇게 설계했는가”가 보이게 작성한다.

예시:

```text
모듈형 스킬 시스템 강의 구조를 포트폴리오 구조로 바꾼 이유
Unity 포트폴리오에서 Feature Module 구조를 사용한 이유
DX11 Render Target Debug를 Unity RenderTexture로 옮기기
```
