# Notion Journal and Weekly Review System

## Notion 개발 일지 시스템

포트폴리오 개발 과정 전체를 기록한다. 목적은 회고, 블로그 작성, 면접 준비다.

```text

2026-06-01

오늘 목표

공부한 개념

구현한 내용

문제 발생

해결 방법

배운 점

다음 작업

관련 Git Commit

관련 Markdown

관련 Blog Draft
```

## Codex와의 주간 리뷰 사이클

Codex는 단순 구현 도구가 아니라 프로젝트 리뷰어 역할도 수행한다.

매주 다음 내용을 정리한다.

### 진행 상황 분석

- 현재 완료된 기능
- 현재 진행 중 기능
- 현재 문서화 상태
- 현재 블로그 상태
- 현재 Notion Journal 상태

### 기술 부채 분석

예시:

```text
Skill System이 Feature Toggle과 연결되지 않음
Validation이 없음
Runtime Assembly 구조가 복잡함
Animation Tool 의존성이 높음
```

### 리팩토링 후보

예시:

```text
Dependency 분리 필요
Interface 추가 필요
Assembly Definition 재구성 필요
UI Presenter 분리 필요
```

### 블로그 후보

예시:

```text
이번 주 가장 가치 있는 학습 내용
기술적으로 설명 가능한 부분
차별화 포인트
실패와 재설계 과정
```

## 주간 리뷰 템플릿

```markdown

## 이번 주 완료

## 진행 중

## 문서화 상태

## 블로그 후보

## 면접에서 설명 가능한 내용

## 다음 주 우선순위
```
