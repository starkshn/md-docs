# Unity Technical Showcase

이 폴더는 Unity 기반 클라이언트 시스템 연구 포트폴리오의 설계 자료를 보존한다.

상세한 기능별 템플릿 문서는 제거하고, 현재는 핵심 설계와 로드맵만 남긴다.

## Purpose

DX11에서 직접 구현했던 엔진 개념을 Unity에서 재해석하고, 클라이언트 시스템 설계 능력을 보여준다.
