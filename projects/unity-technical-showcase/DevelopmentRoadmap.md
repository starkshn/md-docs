# Unity Technical Showcase Roadmap

## Phase 1: Core + Skill

목표: 실행 가능한 최소 기술 시연 구조를 만든다.

- Core Framework
- ModuleHub
- SkillDefinitionSO
- SkillFactory
- SkillInstance
- Target / Condition / Effect 분리
- Skill Tool 최소 버전

## Phase 2: Debug + Showcase

목표: 면접관이 기능 차이를 눈으로 볼 수 있게 만든다.

- Showcase Scene
- Feature Toggle
- Metrics Panel
- Before / After View
- 기본 Debug Log

## Phase 3: DX11 Concept Research

목표: 기존 DX11 경험을 Unity에서 재해석한다.

- RenderTarget -> RenderTexture
- Animation Channel -> Playables
- Prototype Manager -> ScriptableObject + Factory
- Resource Manager -> Addressables 후보
- Object Pool -> Unity Pooling

## Phase 4: Portfolio Polish

목표: 설명 가능한 포트폴리오로 정리한다.

- README
- 핵심 설계 문서
- PlantUML
- 블로그 후보 정리
- 면접 설명 포인트

## Out of Scope For Now

- 서버
- DB
- 로그인
- 매칭
- 멀티플레이
- DOTS / ECS
- CI/CD 심화
