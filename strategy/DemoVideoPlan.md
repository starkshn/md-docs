# Demo Video Plan

## 목적

기술 포트폴리오는 실행 가능한 프로젝트와 코드뿐 아니라 짧은 시연 영상이 필요하다. 면접관과 채용 담당자가 긴 설명 없이도 핵심을 볼 수 있게 만든다.

## 영상 산출물 기준

각 주요 기능 완료 시 다음 중 하나 이상을 만든다.

- 30초 GIF: 기능 변화만 빠르게 보여줌
- 3분 영상: 문제, 적용 전, 적용 후, 구조, Metrics 설명
- 10분 설명 영상: 코드 구조, 문서, UML, 면접 대비 설명

## 영상 구성 템플릿

### 30초 GIF

```text
0~5초: Before 상태
5~15초: Feature Toggle ON
15~25초: After 상태와 Metrics 변화
25~30초: 핵심 구조 한 줄 표시
```

### 3분 영상

```text
0:00~0:20 문제 정의
0:20~0:50 Before 시연
0:50~1:30 After 시연
1:30~2:10 구조 설명
2:10~2:40 Metrics / Debug UI 설명
2:40~3:00 면접용 핵심 요약
```

### 10분 설명 영상

```text
0:00~1:00 기능 목적
1:00~2:30 학습한 개념
2:30~4:00 설계 구조
4:00~6:00 코드 흐름
6:00~7:30 Before/After 비교
7:30~8:30 Metrics
8:30~9:30 문서와 PlantUML
9:30~10:00 회고와 개선 방향
```

## 우선 제작 영상

1. Modular Skill System 3분 영상
2. Skill Editor 3분 영상
3. Feature Toggle + Before/After Framework 3분 영상
4. Animation Preview 30초 GIF
5. Shader Showcase 30초 GIF
6. Object Pooling Before/After 30초 GIF

## 운영 규칙

- 영상은 기능 완성 후 한 번에 만들지 않는다.
- 기능이 KPI Level 3에 도달하면 30초 GIF 후보를 만든다.
- KPI Level 5에 도달하면 3분 영상 대본을 만든다.
- 영상 대본은 Blog Draft와 Interview Notes에서 재사용한다.
